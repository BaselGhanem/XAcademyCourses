# Day 08 — Report Design Lab (120 minutes)

Audience: every professional field. Base: identical Day07 nine-table semantic model.

| Minutes | Work | Acceptance |
|---|---|---|
| 00–15 | Audit 2 visuals: Keep / Change / Remove | Screenshot and business question |
| 15–35 | Align 4 KPIs, trend, breakdowns, whitespace | Accessible hierarchy and units |
| 35–60 | Build one Report Page Tooltip | Relevant values, no clipping |
| 60–80 | Build one Drillthrough Details page | Correct filter transfer and Back |
| 80–100 | Add Page Navigation | Works on the actual pages |
| 100–115 | Test visuals, filters and accessibility | Numeric parity |
| 115–120 | Explain one design choice and decision | Before/after evidence |

This starter is a PBIP **source project** with instructions, not a completed Tooltip/Drillthrough report. It uses exactly the Day07 model; nothing is implicitly Desktop-tested. Power BI Desktop must open the .pbip and Save As PBIX. Scroller and custom HTML landing pages are optional and not required.
