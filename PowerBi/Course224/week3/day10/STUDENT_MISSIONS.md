# Day 10 - Optional Domain Visual Missions

These are optional extensions, **not the mandatory Capstone**. Each learner selects a question, not a person.

| Domain | Core metric | Optional HTML approach |
|---|---|---|
| Performance/Sales | [Total Revenue], DimProduct[Category] | Sorted horizontal bar |
| Operations | [On Time %], [Completed Orders] | Static-first progress ring |
| Finance | [Budget Achievement %] | Bullet at 100% target |
| Workforce | [Staffing Gap], DimDepartment[Department] | Diverging bar |

Test any DAX in Power BI Desktop against native visuals with identical filters; display zero, BLANK and negative values honestly. The AI lab builds a prompt, not a working DAX Measure. See [Capstone Guide](CAPSTONE_GUIDE.md) for mandatory grading.
