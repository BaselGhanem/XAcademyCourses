## Scope / honesty
- The DAX names/dimensions were verified from report definition JSON inside the provided PBIX. This is NOT a live Power BI Desktop smoke test.
- Animated effects are decorative and must not hide or alter the data series.
- Before & After numbers are an explicitly labelled educational illustration, not a live fetch from Nova.
- HTML Content may not implement all native Power BI visual interactions. Test exact installed edition.
- No trainer-only reference files or scripts are linked from student resources.
