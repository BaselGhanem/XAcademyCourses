شو لازم تحكي للـAI قبل ما تطلب منه HTML Visual؟

16 قرار واضحين. افتح كل بطاقة وشوف ليش العنصر مهم، شو الخطأ الشائع، ومثال من مشروع Nova. الهدف نتعلم طريقة التفكير، مش نحفظ Prompt واحدة.

Prompt ضعيفة

Make an ultimate animated bar chart for sales.

Prompt محترفة

Create a sorted horizontal bar from [Total Revenue] by DimProduct[Category], Top 5, 474×271px. Use static-first bars, #099999, CSS-only decorative shimmer, respect slicers, verify largest category=100%, and return a complete DAX measure.

قاعدة النجاح: Specify → Generate → Validate → Improve

ما في Prompt بتضمن إن كل كود AI صحيح. بعد التوليد، لازم تتأكد بنفسك من الأرقام والـFilter Context وأن الـHTML Content يدعم المؤثر، وأن الرسم يضل صحيح بعد إيقاف الحركة.
