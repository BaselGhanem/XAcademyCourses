# Day 09 - Advanced Interactivity, Any Profession

Continue from the Day08 report using the same verified nine-table Day07 model. No named learner roles.

## 120-minute core
1. Visual / Page / Report filter scopes (15m). Do not apply an unrelated fact column as report-wide filter.
2. Sync a DimDate Year Month slicer between two pages (15m).
3. Create a Show/Hide panel using Selection + Bookmarks. **Display ON; Data OFF; Selected visuals** (25m).
4. Create a Field Parameter using valid model fields, e.g. DimBranch[Region] vs DimBranch[Branch Name] (25m).
5. Dynamic Title for single, multiple and cleared selections (20m).
6. Test interactions and save distinct PBIX after Desktop QA (20m).

## Optional scenarios
Performance: Revenue by Region / Branch. Operations: Completed Orders by Region / Branch. Finance: Budget Variance by Region / Branch. Workforce: Staffing Gap by Department; only use other dimension columns when they actually exist.

Optional: Top N by valid Measure or Relative Date on typed Date. Never invent Grade, Issue Type, Cost Category columns.

## Submission
One working filter panel, synchronized date slicer, field parameter and dynamic title, plus one source-checked insight. The supplied PBIP page is an instruction starter, **not** a pre-built working demo.
