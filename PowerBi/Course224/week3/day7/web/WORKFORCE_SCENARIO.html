الموارد البشرية

سيناريو اختياري لأي متدرب. لا يرتبط بمسمى وظيفي أو اسم شخص.

السؤال

ما فجوات الموارد في الأقسام؟

استخدم Year Month وYear من DimDate. قارن 2026 مقابل 2025 الاصطناعية الموثقة، ولا تفترض وجود بيانات خارج الفترة.

التطبيق

ابنِ أربع KPI Cards وLine Chart شهري وBar Chart وMatrix وSlicers؛ تحقق من الأرقام قبل التنسيق.

Fact/Domain: FactWorkforce. Measure: [Headcount].

DAX Measures

Last Snapshot Date

Last Snapshot Date =
MAX(FactWorkforce[Snapshot Date])

Headcount

Headcount =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Actual Headcount]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))

Planned Headcount

Planned Headcount =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Planned Employees]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))

Available Hours

Available Hours =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Capacity Hours]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))

Required Hours

Required Hours =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Demand Hours]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))

Absent Days

Absent Days =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Absence Days]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))

Staffing Gap

Staffing Gap =
[Headcount] - [Planned Headcount]

Staffing Coverage %

Staffing Coverage % =
DIVIDE([Headcount], [Planned Headcount])

Capacity Coverage %

Capacity Coverage % =
DIVIDE([Available Hours], [Required Hours])

Headcount PM

Headcount PM =
IF(HASONEVALUE(DimDate[Year Month]), CALCULATE([Headcount], DATEADD(DimDate[Date], -1, MONTH)))

Headcount MoM %

Headcount MoM % =
DIVIDE([Headcount] - [Headcount PM], [Headcount PM])

Headcount PY

Headcount PY =
CALCULATE([Headcount], SAMEPERIODLASTYEAR(DimDate[Date]))

Headcount YoY %

Headcount YoY % =
DIVIDE([Headcount] - [Headcount PY], [Headcount PY])

Staffing Coverage % PM

Staffing Coverage % PM =
IF(HASONEVALUE(DimDate[Year Month]), CALCULATE([Staffing Coverage %], DATEADD(DimDate[Date], -1, MONTH)))

Staffing Coverage Change pp

Staffing Coverage Change pp =
IF(NOT ISBLANK([Staffing Coverage % PM]), ([Staffing Coverage %] - [Staffing Coverage % PM]) * 100)
