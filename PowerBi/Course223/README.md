# Power BI — Mariam / Course223

دورة خاصة من 10 ايام لمريم، لتقارير اداء القوى العاملة الصحية ومتابعة اعمال قسم ادارة الاداء بالموارد البشرية.

**الحالة:** مواد اليوم الاول جاهزة، والايام 2–10 خطط مقترحة. التسجيل يضاف بعد الجلسة.

الخطة التفصيلية وفحص البنية وقواعد المؤشرات في [ADAPTATION_PLAN.md](ADAPTATION_PLAN.md).

## الصفحات

- `index.html`: التعريف وخطة الايام العشرة
- `login.html`: دخول مركز الدورة
- `dashboard.html`: الخطة والمواد الجاهزة والتقدم
- `day.html?id=1` الى `day.html?id=10`: محتوى الخطة والتمرين والملفات المطلوب تجهيزها
- `concepts/index.html`: فهرس المفاهيم المقترح حسب اليوم
- `Trainer/index.html`: مساحة تجهيز المدرب

## التشغيل

موقع ثابت دون تبعيات بناء. يمكن رفعه على GitHub Pages او تشغيله محليا بخادم ملفات ثابت.

```sh
python -m http.server 8000
```

## ملفات التحكم

### data.js

- `COURSE_CONFIG`: هوية الدورة ورمز الدخول ورابط اللقاء ومفاتيح التخزين
- `DAYS`: الخطة والمواعيد وحالة الجاهزية وملفات كل يوم
- `requiredFiles`: ملفات مقترحة مطلوب تجهيزها، بلا روابط تنزيل
- `resources`: ملفات فعلية جاهزة فقط
- `ready: false`: يعرض خطة اليوم؛ لا يعرض تسجيله او مواد التطبيق او زر اتمامه
- `ready: true`: يسمح لaccess.js بالتحكم في مواد اليوم

لا تضف موعدا او مدة جلسة او رابط لقاء حتى تتحدد. يمكن تغيير رمز الدخول من `portalPassword`؛ رمز الدورة الحالي لم يتغير. الدخول واجهة محلية كما كان، وليس صلاحيات خادم. تقدم مريم يستخدم مفاتيح Course223 المستقلة عن الدورات الاخرى.

### access.js

- `agenda: "ON"`: يعرض الصفحة الرئيسية والخطة
- `agenda: "OFF"`: يحول الصفحة الرئيسية الى الدخول
- `AUTO`: يفتح اليوم الاول الجاهز، ثم اليوم التالي بعد توفر تسجيل السابق
- `ON / OFF`: فتح او قفل يدوي للمواد الجاهزة
- `ready: false` يمنع عرض المواد حتى عند ضبط اليوم على ON، مع بقاء الخطة متاحة للمراجعة

### videos.js

تسجيلات مريم فقط. كل الايام فارغة حاليا. يحتفظ المشغل بدعم iframe كامل من OneDrive ومعالجة صورة معاينة الفيديو.

## تنظيم المواد عند تجهيزها

استعمل `days/day01/downloads/` للملفات و`days/day01/web/` للمصادر والشرح، وبالمثل لبقية الايام. هذه المسارات تنظيم مقترح؛ تنشأ عند تجهيز المواد، ولا توجد لها روابط مفعلة حاليا.
