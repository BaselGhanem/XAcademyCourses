هدف الجلسة

رح تقدري ربط مصدر، شرح رحلة ETL، وبناء تقرير يجيب: كم موظفا؟ كيف يتوزعون حسب المنشاة والفئة؟ وكيف تتغير النتيجة مع الفلتر؟

بنبلش بـ Excel والتقرير، وبعدين بنجرب باقي المصادر سوا

01 — قبل البداية

نزلي Power BI Desktop من Microsoft على جهاز Windows. فكي حزمة اليوم في مجلد ثابت. افتحي Excel وراجعي اول عشرة صفوف، ثم اجيبي: ما الصف؟ ما الشهر؟ هل المعرف يتكرر؟

02 — الاتصال بملف Excel

من Home اختاري Get Data ثم Excel Workbook، او ابحثي عن الموصل في واجهة Get Data الجديدة. اختاري Workforce_Starting_Snapshot.xlsx، ثم جدول WorkforceSnapshot فقط في Navigator، وبعدها Transform Data. لا تختاري ورقة البيانات وجدولها معا

03 — التحويل في Power Query

سمي الاستعلام Workforce. حددي EmployeeID كـ Text وSnapshotDate كـ Date وFTE كـ Decimal Number، وبقية الحقول كـ Text. راجعي Applied Steps: المصدر ثم التنقل ثم النوع. هذا تحويل بسيط؛ التنظيف المتقدم في اليوم الثاني. اختاري Close & Apply

04 — واجهات البرنامج

Report لبناء الرسوم، Table/Data لمراجعة الصفوف، Model لمراجعة الجداول والعلاقات. تسمية واجهة الجدول قد تختلف حسب النسخة. راجعي Home: Get Data وTransform Data وRefresh، ثم Save

05 — بطاقة عدد الموظفين

اضيفي Card واسحبي Workforce[EmployeeID]. من تجميع الحقل اختاري Count (Distinct)، وليس Sum ولا عدد المنشات. سمي البطاقة عدد الموظفين واضبطي عرض الوحدات لتظهر 168 كاملة. لا تحتاجي كتابة DAX اليوم

06 — التوزيع حسب الفئة

ضيفي Bar chart افقي: Cadre للفئات، وEmployeeID للقيم مع Count (Distinct). فعلي Data labels ورتبي من الاكبر للاصغر. للرسم الثاني استخدمي Doughnut chart: FacilityName في Legend، وعد الموظفين في Values

07 — الفلتر واختبار التفاعل

اضيفي Slicer للحقل FacilityName. اختاري North Training Hospital: يجب ان يتغير العدد الى 48. اختاري Nursing داخل الرسم: العدد 24 عند فلترة التقاطع. امسحي اختيار الرسم والفلتر لعودة 168. طلع معك رقم مختلف؟ راجعي Edit interactions

08 — حفظ التقرير

سمي الصفحة Workforce Overview، واضيفي عنوانا يذكر September 2026. احفظي باسم Mariam_Day01_Workforce.pbix. اغلقي الملف وافتحيه للتحقق من الحفظ. هذا الملف تنشئه مريم اثناء التطبيق؛ لا توجد نسخة PBIX جاهزة ضمن الحزمة

09 — استكشاف المصادر مع المدرب

للمقارنة فقط: Get Data ثم Text/CSV لملف Facility_Master.csv، وText/CSV لملف Facility_Demo.txt مع فاصل Tab، وPDF لملف Facility_Demo.pdf واختيار جدول المنشات في Navigator. يمكن ان يختلف اسم الجدول المستخرج؛ قارني 4 صفوف. لمصدر Web افتحي صفحة Facility_Directory.html العامة واستخدمي رابطها عبر Web مع Anonymous. لا تستخدمي رابط GitHub tree او blob كجدول بيانات. اذا لم تكن الصفحة منشورة استخدمي CSV المحلي. لا تربطي هذه المصادر بالتقرير اليوم

10 — لمحة اضافية حسب الوقت

اعرضي CSV البديل للموظفين في ملف Power BI جديد فقط، ليظهر انه يحمل نفس 168 موظفا. اظهري Mobile layout كعرض موجه اذا بقي وقت. لا يعد النشر او تسجيل الدخول للخدمة شرطا لحفظ التقرير المحلي

المفاهيم بامثلة مريم

ETL

Extract: قراءة الملف، Transform: ضبط النوع، Load: تحميل جدول Workforce الى النموذج

Excel vs CSV

Excel يحتوي اوراقا وجداول وتنسيقا؛ CSV جدول نصي بفاصل، بلا اوراق او تنسيق

Power Query

مكان تجهيز البيانات بخطوات يعاد تنفيذها عند التحديث، منفصل عن صفحة التقرير

Count vs Distinct Count

العد الفريد يمنع عد المعرف نفسه مرتين. البيانات اليوم فريدة، لكن اختيار التجميع الصحيح اساس الايام القادمة

Card / Chart / Slicer

البطاقة تجيب كم، الرسم يوضح التوزيع، والفلتر يحدد الجزء الذي نريد مراجعته

Headcount vs FTE

موظفان بنصف دوام = موظفان في العدد و1 في FTE. اليوم نتعلم العدد، وقياسات FTE التفصيلية لاحقا

Snapshot

اللقطة تمثل وضعا في تاريخ واحد؛ لا تجمعي عدد سبتمبر مع عدد اكتوبر كعدد موظفين حالي

Report vs Dashboard

اليوم نبني صفحة تقرير داخل Desktop؛ الداشبورد بمعناه التقني في الخدمة موضوع لاحق

حل المشكلات

  • ظهور مجموع خاطئ: تاكدي من Count (Distinct) للحقل EmployeeID
  • تضاعف العدد: تاكدي انك لم تجمعي Excel وCSV لنفس الموظفين
  • الفلتر لا يؤثر: استخدمي حقول Workforce نفسها وراجعي تفاعل العناصر
  • فشل Refresh بعد نقل الملف: اعيدي تحديد مكان المصدر من Data source settings
  • تشوه CSV: اختاري UTF-8 والفاصل Comma
