اختبارات منطقية

  1. 10,000 هو عدد تقييمات KPI، وليس عدد الموظفين
  2. 820 عدد الاشخاص موضع التقييم بجميع الاتجاهات: 800 موظف و20 مديرا
  3. 4800 + 4800 + 400 = 10000، كل اتجاه مستقل
  4. ObjectiveWeight مكرر عبر KPIs؛ لا يجوز SUM(ObjectiveWeight) على الصفوف
  5. لا نحسب متوسط Self + Manager + Upward لنصنع تقييما عاما واحدا
  6. ملف التدريب لا يعني ان البيانات الحقيقية للمؤسسة تسجلها بنفس البنية
