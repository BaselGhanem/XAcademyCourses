02 / DAX MEASURES ACTUALLY TAUGHT

الكود الذي نراجع عليه بالمحاضرة القادمة

Assessment Count
Assessment Count =
COUNTROWS('EvaluationScores_2026_H1')
Employee Count
Employee Count =
DISTINCTCOUNT(Employees[EmployeeID])
Manager KPI Average
Manager KPI Average =
CALCULATE(
    AVERAGE('EvaluationScores_2026_H1'[KPIScore]),
    'EvaluationScores_2026_H1'[AssessmentSource] = "Manager"
)
Self KPI Average
Self KPI Average =
CALCULATE(
    AVERAGE('EvaluationScores_2026_H1'[KPIScore]),
    'EvaluationScores_2026_H1'[AssessmentSource] = "Self"
)

هذه متوسطات KPIs الخام؛ ليست نتائج Weighted Performance. عدد الموظفين من Employees ليس بالضرورة عدد الموظفين ذوي تقييم مكتمل
