POWER BI / NEW MEASURE

Manager Objective Score (Complete)

Manager Objective Score (Complete) =
VAR ExpectedKPIs =
    CALCULATE(COUNTROWS(KPIs))
VAR ReceivedKPIs =
    CALCULATE(
        DISTINCTCOUNT('EvaluationScores_2026_H1'[KPIID]),
        'EvaluationScores_2026_H1'[AssessmentSource] = "Manager",
        NOT(ISBLANK('EvaluationScores_2026_H1'[KPIScore]))
    )
RETURN
    IF(
        ExpectedKPIs > 0 &&
        ReceivedKPIs = ExpectedKPIs &&
        HASONEVALUE('Calendar'[QuarterLabel]),
        [Manager KPI Average],
        BLANK()
    )
شرح المدرب

ابدأ من علاقة Objectives → KPIs → EvaluationScores، واشرح فحص ExpectedKPIs مقابل ReceivedKPIs قبل المتوسط

مع اختيار Quarter واحد، نقص KPI لا يصبح 0 بل يعيد BLANK، ومدخل Manager KPI Average من اليوم الخامس

POWER BI / NEW MEASURE

Manager Employee Weighted (Complete)

Manager Employee Weighted (Complete) =
VAR OneEmployee = HASONEVALUE(Employees[EmployeeID])
VAR OneQuarter = HASONEVALUE('Calendar'[QuarterLabel])
VAR RequiredObjectives =
    CALCULATETABLE(
        VALUES(Objectives[ObjectiveID]),
        Objectives[PlanYear] = 2026
    )
VAR ExpectedObjectives = COUNTROWS(RequiredObjectives)
VAR CompleteObjectives =
    COUNTROWS(
        FILTER(
            RequiredObjectives,
            NOT(ISBLANK([Manager Objective Score (Complete)]))
        )
    )
VAR TotalWeight =
    CALCULATE(
        SUM(Objectives[ObjectiveWeightPct]),
        Objectives[PlanYear] = 2026
    )
VAR WeightedResult =
    SUMX(
        RequiredObjectives,
        [Manager Objective Score (Complete)] *
        DIVIDE(CALCULATE(MAX(Objectives[ObjectiveWeightPct])), 100)
    )
RETURN
    IF(
        OneEmployee &&
        OneQuarter &&
        ExpectedObjectives > 0 &&
        CompleteObjectives = ExpectedObjectives &&
        TotalWeight = 100,
        WeightedResult,
        BLANK()
    )
شرح المدرب

هذه هي SUMX الرئيسية: تتكرر على Objectives للموظف وليس KPIs داخل Fact

الوزن ObjectiveWeightPct هو 0–100، لهذا نستخدم DIVIDE(...,100)

التأكد من اكتمال كل اهداف الموظف ومجموع الاوزان 100 ضروري قبل النتيجة

POWER BI / NEW MEASURE

Manager Weighted Score (Complete)

Manager Weighted Score (Complete) =
IF(
    HASONEVALUE('Calendar'[QuarterLabel]),
    AVERAGEX(
        VALUES(Employees[EmployeeID]),
        [Manager Employee Weighted (Complete)]
    ),
    BLANK()
)
شرح المدرب

لرسم الاداء حسب القسم لا نستخدم SUM لنتائج الموظفين بل AVERAGEX لموظفين مكتملين

اختبر Quarter واحدا، وتاكد ان BLANK لا يدخل كقيمة صفر

19:38–19:55 — REMOVEFILTERS + Department Contribution %

شو احكي

المدير شاف تقييمات القسم، وسالني كم نسبتها من كل التقييمات لنفس الربع. هون ما بدنا متوسط، بدنا نسبة مساهمة عدد السجلات.

شو اعرض

استخدم Assessment Count الموجود. انشئ Assessment Count All Department Names بواسطة CALCULATE([Assessment Count],REMOVEFILTERS(Departments[DepartmentName])). ثم Department Contribution % = DIVIDE([Assessment Count],[Assessment Count All Department Names]). اختبر على Departments[DepartmentName] داخل Bar أو Matrix، واحتفظ Quarter filter.

تطبيق مريم

تغير قسمين وتشرح لماذا المقام ثابت على نفس الربع، ولماذا المجموع بالمئة يعبر عن عدد التقييمات وليس عن درجات الاداء.

الاسم Contribution % هنا يخص Assessment Count حصرا؛ لا تعرضه كنسبة تقييم موزون. اذا كان Slicer من Employees بدلا من Departments سيحتاج الفلتر المرجعي تعديلا.

قاعدة الشرح: سؤال اداري → مقاييس قصيرة → تطبيق بصري → فحص. لا تحول الجلسة الى حفظ صيغ طويلة، ولا تعرض مفاتيح التحقق على شاشة مريم.

POWER BI / NEW MEASURE

Assessment Count All Department Names

Assessment Count All Department Names =
CALCULATE(
    [Assessment Count],
    REMOVEFILTERS(Departments[DepartmentName])
)
شرح المدرب

المقام يمثل عدد التقييمات عبر الاقسام بعد تجاهل فلتر اسم القسم فقط

تأكد ان Department slicer والمحور يستخدمان Departments[DepartmentName]، وCalendar ما زال يحدد الفترة

POWER BI / NEW MEASURE

Department Contribution %

Department Contribution % =
DIVIDE(
    [Assessment Count],
    [Assessment Count All Department Names]
)
شرح المدرب

الناتج نسبة عدد تقييمات القسم، مش نسبة الاداء الموزون

حوّل Measure الى Percentage واختبر قسمين مع Quarter واحد
